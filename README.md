# 株式会社 上田製作所 コーポレートサイト

株式会社 上田製作所のホームページ制作用リポジトリです。

## 開発環境

- Node.js 22.13.0 以上
- React 19
- TypeScript
- Vinext / Vite
- Tailwind CSS
- shadcn/ui

## セットアップ

```bash
npm install
npm run dev
```

本番用ビルドは `npm run build`、コード検査は `npm run lint` で実行できます。
