## 特徴・強み

1. **多品種の部品製造**  
   ねじ切り機関連だけでも約70種類。さまざまな形状・用途の部品加工を行う。
2. **複数の工作機械を活用した加工**  
   NC旋盤を中心に、製品に合わせて各種工作機械を使い分ける。
3. **少数精鋭の製造体制**  
   従業員3名で、一つひとつの製品に柔軟に対応する。
4. **金属加工以外にも対応**  
   金属部品に加えてゴム部品の製作にも対応する。
5. **メンテナンス分野への展開**  
   部品を「つくる」だけでなく、機械を「守る」分野へ事業を広げる予定。
